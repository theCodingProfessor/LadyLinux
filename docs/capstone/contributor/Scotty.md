# Lady Linux - Frontend Enhancements and UI Contributions

## Overview

This document outlines my contributions to the LLM project, primarily focused on improving the user interface, usability, and visual consistency. The work includes styling improvements, theming support, fullscreen functionality, and syntax-related fixes.

## Key Contributions
1. Theme Additions:
New Jungle and dark mode were added to the group of JSON files, which are then pulled by the user when switching themes. 
2. Fullscreen Functionality:
Added fullscreen mode for an improved/app feel for the lady linux website. Works different screen sizes with responsive behavior.
3. Syntax Fixes:
Fixed some slight inconsistencies in syntax across different files, improved formatting with GitHub Copilot and syntax.

## Main takeaway

What I learned from this project is how to work with a team of developers, how to use GitHub for version control and collaboration, and how to implement frontend features that enhance the user experience. I also gained experience in working with themes and responsive design, which are crucial for modern web development. Overall, this project has been a valuable learning experience and has allowed me to contribute meaningfully to the LLM project.
